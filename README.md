# itaku-keisan

# 委託販売 精算書ジェネレーター

RECOREからエクスポートしたCSV / Excelデータをアップロードするだけで、委託者ごとの精算書（Excel / PDF）を一括生成するWebアプリです。

🔗 **アプリURL**: https://ueda-recore.github.io/itaku-keisan/

---

## 使い方

### STEP 1 — ファイルを読み込む
- RECOREからエクスポートしたCSVまたはExcel（.xlsx）をドラッグ＆ドロップ、またはクリックして選択

### STEP 2 — 列の対応を設定
- 委託者名・商品名・売価・数量・委託料などの列を選択（RECOREの列名は自動検出）

### STEP 3 — 委託料率を設定
- CSVから自動検出した委託者ごとに料率（%）を設定
- 未設定の委託者にはデフォルト料率が適用される

### STEP 4 — 精算書を一括生成
- ボタン1つで委託者全員分を生成
- 委託者ごとにExcel / PDFを個別ダウンロード

---

## 対応ファイル

| 入力 | 出力 |
|------|------|
| CSV (.csv) | Excel (.xlsx) |
| Excel (.xlsx / .xls) | PDF（印刷プレビュー経由） |

---

## 精算書の内容

- 会員名（委託者名）
- 商品名 / 在庫コード
- 販売方法・売価・委託料率・委託料・支払額
- 合計売上 / 合計委託料 / お支払金額
- 支払方法・支払予定日・備考欄

---

## 技術仕様

- 純粋なHTML / CSS / JavaScript（サーバー不要）
- ファイル処理はすべてブラウザ内で完結（データは外部送信されない）
- ExcelはSheetJS（xlsx.js）で生成
- GitHub Pagesでホスティング
